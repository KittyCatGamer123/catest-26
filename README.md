# Computational Arts 2026 Lab Test
In-class examination related to the Godot Engine for Computational Arts *(2025-26, Semester 2)*.

## Requirements
- "Traffic Lights" arranged in a circle
- - They start randomly as green, amber or red
- - They transition green - amber - red and back to green based on a random interval
- - The labels show how many are green, amber or red at any time
- Using 2D or 3D nodes as you wish. 
- Should have a subscene for a single traffic light.
